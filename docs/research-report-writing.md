# 调研报告怎么拆、怎么写

先弄清读者想知道什么、正在做什么选择。拆题是为了让每个答案都能改变读者对原问题的判断。题数、篇幅和章节随问题变化。

**研究时由分到总，写作时由总到分。** 先用一句话说清研究对象。逐题去找能直接回答它的记录，分清已观察到的事实、据此作出的推断，以及待验证的假设。然后判断：哪一题给出了支持，哪一题限制了结论，哪些答案即使成立也不足以作出决定。

以《个性化选衣与服装销售》为例，选衣服务改变的是挑衣服的过程，收入来自卖出的衣服。要回答“这门生意值不值得做”，研究不能停在“大家爱看穿搭”：需求、真实成交、退款后留下的钱要分别回答。同类公司卖出过衣服，也不等于我们的顾客愿意从现有平台切换。

- **拆题。** 问“搭配建议能否让同样的商品多卖、少退”，比列一个“商业模式”章节更容易调研。写下什么答案会改变决定，以及到哪里能找到这样的证据。对纯事实题，用来历、对象或时间等必要区分，不硬套商业问题。
- **调研。** 数字旁边写明谁发布、比较了哪些人或商品、发生在什么时候。产品公告能证明功能推出；案例可以证明某次试点出现过结果。两个引擎都引用同一份原文，仍只是一份证据。原文没核实就明确说清。
- **逐题回答。** 每题先写一句读者能复述的话，再用最有解释力的事实、对照或反例支撑它。“有成交改善的实例；退款后是否多赚钱还不知道”，就是一个完整答案。若分析没有跑完，要说分析未完成，不能写成行业没有证据。
- **综合。** 先直接答最初的问题，再解释哪个分题让选择成立、哪个限制投入规模。在选衣案例中，有人下单支持试销；缺少留购、复购和服务成本的数据，就不能主张扩大投入。总判断不是把几个分数求平均。
- **写给读者。** 首页放总判断与各题短答案；完整论据按题展开，出处贴近事实。下一步只写能改变判断的验证，并交代出现什么结果该继续或停止。已核清的事实题可以直接结束。百分比评级、抓取日志和引擎术语留在执行记录。

交稿前只读标题、总判断和每题首句：能否复述答案？再从总判断反向检查：有没有哪一步拿点击当成交、拿成交当利润、拿他人的案例当成自己的结果？有就收窄这句话，或补证据。
